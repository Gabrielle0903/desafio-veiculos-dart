# Desafio de Cadastro de Veículos (Dart + Supabase)

Aplicação de terminal em Dart para gerenciar o estoque de veículos de uma concessionária integrado ao Supabase.

## Configuração

1. Crie a tabela `veiculos` no SQL Editor do Supabase:
```sql
create table public.veiculos (
  id bigint generated by default as identity primary key,
  marca varchar(50) not null,
  modelo varchar(100) not null,
  ano integer not null,
  valor decimal(15,2) not null,
  quilometragem integer not null
);
```

2. Preencha o arquivo `.env` na raiz do projeto com as suas credenciais:
```env
SUPABASE_URL=sua_url_do_supabase
SUPABASE_PUBLISHABLE_KEY=sua_chave_publica
```

3. Instale as dependências:
```bash
dart pub get
```

## Execução

Na raiz do projeto, execute:
```bash
dart run bin/main.dart
```
